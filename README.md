
  # Portfolio - Andrea Will

  Site portfolio personnel, dark mode avec animations.

  ## Stack

  - React 18
  - Vite
  - Tailwind CSS v4
  - Motion (Framer Motion)
  - Lucide React (icônes)

  ## Lancer le projet

  ```bash
  pnpm install
  pnpm dev
  ```

  Le site sera disponible sur `http://localhost:5173/`

  ## Build de production

  ```bash
  pnpm build
  ```

  Les fichiers générés seront dans le dossier `dist/`.
